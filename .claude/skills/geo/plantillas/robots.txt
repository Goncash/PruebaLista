# ─────────────────────────────────────────────────────────────────────────────
# PLANTILLA robots.txt — acceso de buscadores y motores de IA
#
# ⚠️ VERIFICA LOS NOMBRES ANTES DE DESPLEGAR.
# Una regla solo funciona si el User-agent está escrito EXACTAMENTE como el
# rastreador se anuncia. "GPT-Bot" en vez de "GPTBot" falla en silencio.
# Los proveedores cambian y añaden bots; consulta la documentación oficial de
# cada uno (OpenAI, Anthropic, Google, Perplexity, Common Crawl) antes de
# publicar este archivo. La lista de abajo es un punto de partida, no una
# verdad permanente.
#
# ⚠️ Y LO MÁS IMPORTANTE: robots.txt controla el RASTREO, no la CITA.
# Permitir a todos los bots no hace que te citen. Bloquearlos sí garantiza que
# no puedan hacerlo. Es condición necesaria, nunca suficiente.
# ─────────────────────────────────────────────────────────────────────────────
